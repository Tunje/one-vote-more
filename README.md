# One Vote More ("its just political")

A colony political simulator: a 151-seat parliamentary democracy on a new planet, built in Godot 4.7 (GDScript).

- Design documents: `project.md`, `economic-simulator.md`, `companies.md`, `justiceAndLaw.md`, `staffAndSkills.md`
- Plans, specs and decisions: `planning/` (start with `planning/MASTER-PLAN.md`)
- The game: `game/` (open `game/project.godot`; tests: `bash game/tools/test.sh`)
